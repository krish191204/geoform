# Design & animation skills (Emil Kowalski)

Source: [emilkowalski/skills](https://github.com/emilkowalski/skills)

Use these when changing Geoform UI, UX, or motion:

| Skill | When |
| --- | --- |
| **emil-design-eng** | Default for polish, buttons, shadows, transitions, taste |
| **animate** | Building a new animation from scratch |
| **review-animations** | Critiquing motion in a diff |
| **improve-animations** | Auditing the whole app’s motion |
| **find-animation-opportunities** | Deciding what should / shouldn’t move |
| **apple-design** | Fluid, Apple-adjacent interface principles |
| **pick-ui-library** | Toasts, drawers, menus — don’t hand-roll |
| **ask-sonner** | Toast library recipes |

Motion tokens live in `src/style.css`: `--ease-out`, `--ease-in-out`, `--dur-press`, `--dur-fast`, `--dur-ui`.
